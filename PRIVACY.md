# Privacy

No provider telemetry endpoint. State contains profile references, salted subscription identity hashes, binding metadata, usage counters and tool argument digests, never credentials. Official runtime transcripts are owned by the official client. The provider's SQLite directory is mode 0700 and database mode 0600. Diagnostic export excludes profile paths, aliases, prompts, tool bodies and credentials. Never attach private state or official transcripts to issues. Logs from external tools may contain private data and require separate review before sharing.
