# Security

Report vulnerabilities privately using GitHub private vulnerability reporting for this repository when enabled. Otherwise contact the maintainer through their GitHub profile to arrange a private channel; do not put credentials or exploitation details in a public issue. Never paste tokens, profile contents or raw conversation transcripts.

Protect authentication/profile boundaries, DSH tool authority, canonical history, ledger state, release evidence and CI credentials. Public PR checks receive no Claude credentials. Candidate AI patches cannot approve themselves. Protected policy, workflow, release, authentication and routing changes require maintainer review. Do not bypass organization-managed restrictions or automatically rerun an uncertain side effect.
